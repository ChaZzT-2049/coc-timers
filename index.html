Sigue los constructores sin estar pegado al juego

La API pública de Clash of Clans no incluye tiempos de mejora. Esta app lee el JSON que exporta el propio juego y calcula cuándo termina cada timer.

  1. En Clash of Clans abre Ajustes → Más ajustes.
  2. Abajo del todo, Exportar datos de la aldea en JSON → Copiar.
  3. Vuelve aquí, pega el JSON y activa las notificaciones.

El export es una foto del momento en que pulsas Copiar. Si usas pociones, Pase de Oro, ayudantes o cancelas una mejora, vuelve a exportar para recalcular.
